# Lecture Decks

Canonical copies of the CSCI 3753 lecture slides. Edit HERE — this
directory is the source of truth. The .pptx files are gitignored: they
live only on the instructor's machine and are never pushed (the
originals are in base-camp's history, commit 90e0db9); the schedule that pairs each deck
with its date and keywords is `ta/schedule.md` in the base-camp repo.
