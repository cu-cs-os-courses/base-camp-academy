Part 1 · follow along

Strings are pointers

Your TA types this live. Type it with them.

#include <stdio.h>#include <string.h> int main(int argc, char *argv[]) { for (int i = 0; i < argc; i++) printf("argv[%d] = \"%s\" (%zu chars)\n", i, argv[i], strlen(argv[i])); return 0;}
gcc -Wall -Werror -o args args.c./args hello "two words" ''
  • argv is an array of argc pointers. Each one points to characters that end with a '\0' byte.
  • strlen counts characters up to the '\0', but it does not count the '\0' itself.
  • The shell splits the command line into words, and quotes keep "two words" as one argument.
The bug everybody writes once

char name[5]; strcpy(name, "hello"); writes six bytes, five letters plus '\0', into five. With -Wall -Werror, GCC refuses to compile it. Without the flags it compiles and even prints hello, because undefined behavior often looks fine. Build it with -fsanitize=address -g and run it again, and AddressSanitizer names the line that overflowed. When a C program acts strangely, try that first.

Part 2 · follow along

Shell plumbing

Run these inside the VM, because /proc exists only on Linux.

cat /proc/meminfo | head -3 # pipe: output of one → input of the nextgrep MemFree /proc/meminfo # kernel files read like textls /proc | wc -l # count entriesls /nonexistent > out.txt # the error still shows: it is stderrls /nonexistent > out.txt 2>&1 # both streams into the fileecho $? # exit status of the last command; 0 = successman 3 strlen ; man 2 read # 3 = C library, 2 = system calls

Some useful keys follow. Tab completes a name. Ctrl-C stops the running program. Ctrl-D ends input. Ctrl-a x quits the VM.

How to ask a good question

Have the terminal open with the error on screen. Say what you ran, what you expected, and what you saw instead, and what you already tried. TAs will point you to the right lecture section, manual page or debugging step. They will not write your lab for you.

Cheat sheet

gcc -Wall -Werror -o p p.cCompile with all common warnings, treated as errors. Every lab builds this way.
gcc -fsanitize=address -g …Catch buffer overflows and use-after-free at run time, with line numbers.
a | bPipe. a's standard output becomes b's standard input.
< f   > f   >> fRead stdin from f / write stdout to f / append to f.
2> f   2>&1Redirect stderr to f / merge stderr into stdout.
echo $?Exit status of the last command, where 0 means success.
man 2 open · man 3 printfManual pages. Section 2 is system calls, section 3 is the C library.
make run · Ctrl-a xBoot the course VM / leave it.
SHARE=$PWD/dir env/run.shBoot with a host directory mounted at /share in the VM.
